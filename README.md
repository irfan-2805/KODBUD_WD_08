# Task 8 - Animated Webpage

An enhanced version of the Task 2 landing page with **CSS animations** and **@keyframes** added throughout, built as part of my Web Development Internship at **Kodbud**.

---

## Task
**Task 8 - Add Animations to a Webpage**
> Take any webpage made earlier and add CSS transitions or animations. Use @keyframes for custom effects like fade-in and slide-in.

---

## Animations Used

| Animation | Effect | Applied To |
|-----------|--------|------------|
| `@keyframes fadeInDown` | Fades in from top | Hero heading, CTA title |
| `@keyframes fadeInUp` | Fades in from bottom | Hero text, testimonial cards |
| `@keyframes zoomIn` | Scales in from small | Feature cards (staggered) |
| `@keyframes pulse` | Continuous scale pulse | CTA primary button |
| `@keyframes navSlide` | Slides in from top | Navbar on page load |
| `@keyframes countUp` | Fades up with delay | Stats bar items |
| `CSS transition` | Smooth hover effects | Cards, buttons, nav links |
| Icon rotate | Rotates on hover | Feature card icons |
